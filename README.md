# ☝️ DALA MOTION — веб-камера вместо мыши. Играй в Dota 2 рукой

**Admit Hackathon 2026 · кейс «Motion» · направление C / FREE (управление жестами) + A / GAME**

Открываешь сайт, включаешь веб-камеру — и твоя рука становится мышью:

| Жест | Что происходит |
|---|---|
| ☝️ Указательный палец | курсор мыши |
| 👌 Большой + указательный | правый клик — герой идёт в эту точку. Держишь — идёт за курсором |
| ✊ Кулак + движение руки | камера, как джойстик: сдвинул кулак влево — камера едет влево |
| 🤏 Большой + средний | способность (Q, настраивается) |
| ✊✊ Два кулака | ульта (R, настраивается) |

На экране камеры рука обведена линиями, а кончики пальцев подсвечены цветами: большой 🔵, указательный 🟢, средний 🔴, безымянный — бирюзовый, мизинец 🟣.

**Два режима:**

1. **⚔️ Тренировочная арена** — полностью в браузере, ничего не нужно устанавливать. Мини-MOBA на большой карте: 5 волн духов степи и босс, мини-карта, счёт, итоги, рекорды. Жюри может проверить весь проект только по ссылке.
2. **🎮 Режим Dota 2** — те же жесты управляют настоящей Дотой. Браузер не может двигать системную мышь (это запрещено ради безопасности), поэтому рядом запускается крошечный помощник `bridge/dota_bridge.py` — только стандартный Python, без `pip install`. Распознавание, режим ошибки и весь интерфейс остаются в браузере; помощник только нажимает то, что ему сказал сайт.

🔗 **Демо:** https://clijjiki.github.io/dala-motion/

## Как запустить

### Арена (только браузер)
1. Открой ссылку в Chrome / Edge, нажми **«Включить камеру»**.
2. **Калибровка:** покажи раскрытую ладонь там, где удобно держать руку, замри на секунду.
3. Меню управляется рукой: наведи палец на кнопку и сведи 👌 (или просто подержи).
4. **Тренировочная арена** → обучение из 5 шагов → бой.

### Dota 2
1. Запусти помощника в папке проекта:
   ```bash
   python bridge/dota_bridge.py
   ```
2. В Доте: **Настройки → Видео → Окно без рамки** (Borderless). Для способностей включи **быстрое применение** (Quick Cast).
3. На сайте: **Режим Dota 2** → индикатор «мост подключён» → **«Мини-окно камеры»** (окно с камерой поверх Доты, как в роликах) → **«Начать управление»**.
4. **F8** — мгновенная пауза/продолжить (работает прямо в Доте). Спрятал руку из кадра — управление остановилось, все клавиши отпущены.

> Помощник слушает только `127.0.0.1` (к нему нельзя подключиться с другого компьютера) и сам отпускает клавиши, если сайт замолчал. Тестируйте в лобби или против ботов.

## ⚠️ Режим «ошибка» (твист)

Приложение ловит не только правильные жесты, но и **«почти жесты»** и говорит, что конкретно исправить. Подсказка показывается плашкой и озвучивается голосом (в Доте ты смотришь в игру, а не на сайт). На экране камеры **красным обводятся именно те пальцы**, которые надо поправить.

**1. Ошибки техники жеста** (собственные правила поверх 21 точки кисти, `js/gestures/recognizer.js`):

| Что заметили | Что подсказываем |
|---|---|
| Большой и указательный близко, но не сомкнуты | «Сомкни большой и указательный до касания — между ними ещё ~1.5 см» (сантиметры считаются по размеру ладони) |
| То же для среднего | «Дотянись большим пальцем до СРЕДНЕГО — осталось ~1 см» |
| Большой касается сразу двух пальцев | «Большой палец касается и указательного, и среднего. Чтобы идти — только к указательному, для способности — только к среднему» |
| Кулак собран не до конца | «Кулак не собран: разогнут мизинец — сожми его, чтобы двигать камеру» |
| Ульта: одна рука в кулаке, вторая нет | «Для ульты сожми в кулак ОБЕ руки — у второй руки разогнут указательный и средний» |
| Ладонь повёрнута ребром | «Разверни ладонь к камере — пальцы перекрывают друг друга» |
| Рука далеко / близко / у края кадра | «Поднеси руку ближе…», «Отодвинь руку…», «Верни руку к центру…» |

**2. Тактические ошибки на арене** (`js/main.js → handleArenaEvents`): после каждого пропущенного удара объясняем, какой жест помог бы:
- «Тебя бьют за краем экрана! Сожми кулак ✊ и сдвинь руку к жёлтой стрелке — камера поедет к герою»
- «Удар босса! Когда под ним красный круг — щипком 👌 уйди за край круга»
- «Два кулака распознаны, но ульта заряжена на 60%…», «Много промахов: сначала наведи палец на врага…»

**3. Разбор после игры:** на экране итогов показываем топ-3 ошибки с количеством повторов.

Подсказки не спамят: тренер (`js/gestures/coach.js`) показывает одну и ту же подсказку не чаще раза в 4.5 с, любые — не чаще раза в 1.6 с. Подсказка срабатывает, только если «почти жест» держится дольше ~0.5 с.

## Своя логика распознавания

MediaPipe отдаёт только 21 точку каждой кисти. Всё остальное написано командой:

- **Жесты — геометрические правила**, нормированные на размер ладони, поэтому не зависят от расстояния до камеры (`handmath.js`): разгибание каждого пальца, расстояния щипков, поворот ладони.
- **Гистерезис** (разные пороги «нажать» и «отпустить») — щипок не «дребезжит».
- **Две руки:** основная рука отслеживается по положению, два кулака = ульта, один кулак = камера.
- **Кулак-джойстик:** точка, где сжал кулак, — центр; смещение руки → направление и скорость камеры, с мёртвой зоной.
- **One Euro Filter** — курсор не дрожит, когда палец стоит, и не отстаёт при быстром движении.
- **Клик «из прошлого»:** правый клик берёт позицию курсора ~90 мс назад, до начала сведения пальцев. При щипке кончик пальца смещается, и без этого клик «уезжал» бы.
- **Весь кадр — весь экран:** курсор работает по всему кадру камеры с небольшими полями по краям (у самого края камера теряет руку). В `config.js` можно включить адаптивную зону (`fullFrame: false`): она центрируется там, где пользователь показал руку, и масштабируется под её размер.
- **Работа в фоне:** когда Дота закрывает браузер, `requestAnimationFrame` замирает. Поэтому цикл переключается на таймер из Web Worker, а камера выносится в поверх-окно (Document Picture-in-Picture).

## Запуск локально

Сборка не нужна — это статический сайт на ES-модулях. Камере нужен `localhost` или `https`:

```bash
python -m http.server 8080
```

Открой http://localhost:8080.

**Для разработки:**
- `?sim` — мышь вместо камеры (ЛКМ держать — идти, ПКМ или E — способность, F держать + двигать мышь — камера, R — ульта).
- `?debug` (или Shift+D) — панель с сырыми метриками руки.

## Структура

```
index.html               экраны и HUD
css/style.css            дизайн, адаптив
js/config.js             все пороги и баланс
js/main.js               экраны, режим Dota 2, главный цикл
js/vision/               камера, MediaPipe Hand Landmarker (2 руки), One Euro Filter
js/gestures/             геометрия кисти, жесты + режим «ошибка», курсор, калибровка, тренер
js/game/                 арена: логика, волны, отрисовка, мини-карта
js/bridge/dota.js        клиент моста: склеивает движения курсора, шлёт команды
bridge/dota_bridge.py    помощник Windows: SendInput (мышь, клавиши), F8-пауза, сторож
js/ui/                   HUD, экран камеры (цветные кончики пальцев), курсор-рука для кнопок
js/audio/, js/storage/   звук, голос, рекорды
js/dev/sim.js            режим мыши для разработки
```

## Технологии

- [MediaPipe Tasks Vision — Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (готовая модель, CDN)
- Vanilla JavaScript (ES-модули), Canvas 2D, WebAudio, Web Speech API, Document Picture-in-Picture
- Python 3 (стандартная библиотека: `http.server` + `ctypes` → WinAPI `SendInput`)
